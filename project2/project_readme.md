# Rocher - Furniture Store (Project 2)

Welcome to the **Rocher** furniture e-commerce landing page project! This project is built using HTML5, CSS3, and Bootstrap 5 to create a modern, responsive, and visually appealing web store interface.

## 🔗 Live Demo
Check out the live website deployed on Netlify:  
[https://jazzy-kitsune-a4d3d0.netlify.app](https://jazzy-kitsune-a4d3d0.netlify.app)

---

## 🛠️ Built With
* **HTML5:** Semantic document structure.
* **CSS3:** Custom styling, variables, typography, and responsive adjustments.
* **Bootstrap 5:** Grid layouts, component utilities, and responsive navigation framework.
* **Google Fonts (Poppins):** Clean and modern typography.

---

```text
project2/
```

---

## ✨ Features
* **Sticky Navigation Bar:** Clean header with categorized product links, search icon, and bag counter.
* **Hero Section:** High-impact banner showcasing the featured wooden chair collection with a call-to-action button.
* **Special Category Grid:** Multi-item product category display featuring popular collections, customer review testimonials, and discount promo cards.
* **Features Delivery Bar:** Clear service icons and indicators for free shipping and customer benefits.
* **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile screen sizes.

---

## 🚀 Getting Started Locally
To run this project on your local machine:
1. Clone or download this repository.
2. Ensure you have the folder structure set up with the local `css/` and `js/` folders containing Bootstrap files.
3. Open `index.html` in your web browser or use a tool like **Live Server** in VS Code.
